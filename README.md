# Neverlight Athletics (demo build)
Run locally: `cd neverlight-athletics && python3 -m http.server 8000`, then open http://localhost:8000.
Edit all sample content (brand, programs, coaches, classes, plans, stats) in `js/data.js`.
Everything is sample data. Forms are frontend-only and never send or reserve anything.
Add photos to `assets/images/`. Policies must be reviewed and replaced before any real launch.
## Status
